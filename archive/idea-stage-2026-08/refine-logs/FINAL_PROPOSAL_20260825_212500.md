# FINAL PROPOSAL — Counterfactually Certified Provenance Write-Gating

## Problem Anchor

在严格 label-free 的 hateful-video temporal localization 中，T3AL 会把高相似度 temporal units 当作伪正例并在测试时更新表示。quotation、reporting、counterspeech 和 benign OCR keyword 同样可能具有高 hate similarity，因而成为 adaptation contamination：模型用自己的错误证据强化自己的错误。

## Method Thesis

在任何 temporal unit 获得 adapter write permission 之前，使用保持 hostile payload 不变的 video-side matched interventions，检验 source binding 与 stance context 对 frozen pre-answer representation 的有符号交互效应。只有通过 certificate 的单元进入正/负 reservoir；不确定单元不更新参数。

## Method

### 1. Corrected T3AL base

将原始按绝对帧数触发的采样改成 4-fps rate-consistent quantile sampling。对长度为 \(T\) 的视频，取互斥 top/bottom \(q=\min(\max(4,\lfloor0.1T\rfloor),\lfloor T/3\rfloor)\)；时间 jitter 用秒定义后换算到 4 fps。该步骤是 correctness invariant，不作为贡献。

### 2. Frozen intervention panel

对候选 unit \(t\) 构造四个 deterministic views；最终预测始终使用未修改原视频：

- \(x_t\)：原始 audio/visual/transcript context；
- \(I_P(x_t)\)：仅 mask hostile payload，用于确认 payload sensitivity；
- \(I_B(x_t)\)：保留 payload，但 cyclic-shift active-speaker/audio binding，用于切断 source relation；
- \(I_S(x_t)\)：保留 payload，只 mask 前后 stance context（quotation/reporting/criticism/endorsement cue）；
- \(I_N(x_t)\)：coverage-matched irrelevant context mask，作为 nuisance control。

所有 views 在一次 packed MLLM encoder forward 中取得同一层的 pre-answer representation；不请求模型输出 stance 标签，不使用另一个模型。若 packed forward 与独立 forward 不等价，则改成 frozen encoder batch，并单独报告 call accounting。

### 3. Difference-in-differences certificate

令 \(s(x)\) 为 frozen representation 对 policy-conditioned hate subspace 的 margin。定义：

\[
d_P=s(x)-s(I_Px),\quad d_B=s(x)-s(I_Bx),\quad d_S=s(x)-s(I_Sx),\quad d_N=|s(x)-s(I_Nx)|.
\]

为避免“删掉 slur 就降分”被误认为 commitment，核心量是保留 payload 的 signed interaction：

\[
c_t=(d_B+d_S)-2d_N.
\]

直觉上，asserted/endorsed evidence 在切断 source/stance binding 后应失去支持，\(c_t>0\)；quoted/condemned evidence 的 suppressive context 被移除后，hate margin 可能上升，形成 \(c_t<0\)。这只是待验证机制，不作为既成事实。

阈值只由当前视频的 robust median/MAD 与固定 quantile 决定，不读取标签：

- \(R^+\)：高 payload sensitivity、\(c_t\) 显著为正、nuisance-stable；
- \(R^-\)：低 hostility background，或高 payload sensitivity 且 \(c_t\) 显著为负；
- \(R^?\)：其余全部，零权重。

gate 由适配前 frozen model 计算、stop-gradient，并在全部适配步中固定。

### 4. Write-gated adaptation

仅更新 T3AL 原有 projection/logit-scale 参数，保持原始 update budget 与 norm constraint：

\[
\phi_{k+1}=\phi_k-\eta\sum_t[g_t^+\nabla L_t^+ + g_t^-\nabla L_t^-],
\qquad R^+\cap R^-=\varnothing.
\]

核心可证伪预测是：相对 coverage-matched confidence gate，CCPWG 减少 mention/counterspeech 单元进入 \(R^+\)，并阻止其 score 随 adaptation step 上升，同时保留 asserted-hostility 单元。

### 5. Boundary output（条件模块）

只有 write-gating pilot 通过后，才把状态扩展为 absent / mentioned / committed / conflict 的四状态时间过程，并用固定转移代价输出 interval posterior。它不是独立 novelty claim。

## Call Budget

- 核心 pilot：T3AL/CoCa dense encoder + 一次 packed MLLM representation call/video；不使用第二次 MLLM call。
- 禁止：另一个 LLM 提供 provenance label、逐窗口多次 judge、self-consistency ensemble。
- 如果一次 packed call 无法覆盖全部 views，pilot 判为不符合 ≤2-call charter，必须缩减为 encoder-side deterministic intervention，而不是放宽预算。

## Claims

1. 当前 4-fps T3AL sampling 在绝大多数目标视频上退化；rate-consistent disjoint sampling 恢复有效 TTA（诊断/工程结论）。
2. 普通 T3AL adaptation 会放大 use/mention false-positive evidence。
3. CCPWG 在不使用 labels 的条件下阻止 contamination，并优于 coverage-matched generic gates。
4. 仅在 2–3 成立后，typed state transitions 改善 boundary F1。

## Kill Criteria

若 certificate 在适配前不能在 HateMM 与 MHC-ZH 上控制原始 hate score 后达到 asserted-vs-mentioned AUROC ≥0.70，或 deletion-only/时间-shuffled placebo 同样有效，立即终止该主线。不得通过新 prompt、probe、teacher 或 boundary post-processing 挽救。

## Novelty Position

Novelty 只主张“counterfactually certified provenance controls adapter write permission”。互斥采样、multimodal infrastructure 和 boundary decoder 均不单列贡献。当前独立查新为 POSITIVE、LOW–MEDIUM 4/10；critical review 为 POSITIVE 5.5/10，均是 same-family provisional。
