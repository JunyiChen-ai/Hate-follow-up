# EXPERIMENT PLAN — CCPWG

## Evaluation Protocol

- 数据：HateClipSeg、HateMM、MHC、MHC-ZH；固定现有 test split 与 4 fps grid。
- labels 只在运行完成后的 evaluator 使用；不参与 gate、threshold、超参、early stopping。
- 指标：pooled frame ROC/PR；within-video macro ROC；F1@tIoU 0.3/0.5/0.7；gate coverage 与每步 score trajectory。
- 正式结果：3 seeds；pilot 先做 32–48 个预冻结分层视频。

## Stage 0 — Reproduction Repair

1. 恢复 T3AL repo、CoCa 4-fps extractor 与 captions。
2. 在 32-video manifest 重新运行原始 `D_anet`、no-TTA、disjoint-rate TTA。
3. 确认每个视频 \(R^+\cap R^-=\varnothing\)，并记录 update gradient norm 非零。

**通过条件**：corrected TTA 相对 no-TTA 产生非零且可复现的表示/score 变化；否则先修复工程，不进入方法实验。

## Stage 1 — Certificate Kill Test

预冻结四个 strata，各约 8–12 视频：asserted/endorsed、quoted/reported/counterspeech、benign OCR/title keyword、clean benign。覆盖 HateMM、MHC-ZH，能覆盖时加入 HateClipSeg/MHC。

比较：

1. raw score；
2. payload deletion only；
3. source-binding intervention；
4. stance-context intervention；
5. full difference-in-differences certificate；
6. time/provenance shuffled placebo；
7. nuisance mask placebo。

**主通过条件**：两个重点语料分别 residual AUROC ≥0.70；shuffled/deletion-only 不达标；asserted admission ≥ confidence gate 的 80%；use/mention admission 下降 ≥30%。

## Stage 2 — Adapter Write-Gating

固定 certificate 后比较：

- frozen/no adaptation；
- sampling repair only；
- coverage-matched random gate；
- confidence/PCS gate；
- modality-agreement gate；
- provenance feature without counterfactual certificate；
- CCPWG score-time filtering only；
- CCPWG write-gating only；
- full CCPWG；
- gate frozen vs recomputed during adaptation。

**主通过条件**：至少两个数据集上 PR-AUC 与 within-video ROC 同时超过 corrected T3AL 和 generic gates；mention scores 不随更新系统性上升；不是由减少 update 数量解释。

## Stage 3 — Boundary Module（仅在 Stage 2 通过后）

比较简单 threshold、generic change-point 与 absent/mentioned/committed/conflict 四状态 posterior。主看 F1@0.3/0.5/0.7，要求不牺牲 Stage 2 的 frame ranking。

## Stage 4 — Full Benchmark

四数据集、三种子统一冻结配置；同时报告各库结果和 macro，不只报平均。加入 channel removal、ASR corruption、music-only audio、OCR keyword、quotation/counterspeech strata。

## First Three Runs

1. `R0`: 32-video original/no-TTA/disjoint-rate sampler sanity。
2. `R1`: frozen intervention panel + shuffled/nuisance controls，不做 adaptation。
3. `R2`: coverage-matched generic gates vs CCPWG write gate，记录逐步 score trajectories。

## Compute Budget

- R0：约 1 GPU-hour；
- R1：目标 ≤2 GPU-hour，packed representation forward；
- R2：约 1–2 GPU-hour；
- discovery pilot 总预算 ≤8 GPU-hour。
