# T3AL 改进 Idea Discovery Report

**方向**：Label-free 多模态 hateful-video temporal localization；提升 T3AL 的帧级排序与事件边界，同时形成机制创新  
**日期**：2026-08-25  
**流程**：research-lit → idea-creator → novelty-check → research-review → research-refine-pipeline

## Executive Summary

推荐主线是 **Provenance-Gated Multimodal T3AL（PG-T3AL）**：不再让 T3AL 仅凭视觉相似度挑选伪正负帧，而是建立视觉、timestamped transcript 与音频的独立证据 reservoir；只有能证明内容来源、目标、行为和作者 commitment 的证据才允许写入 test-time adapter。模型输出两个随时间变化的状态——“hostile content 被观察到”和“hostility 被作者 assert/endorse”——边界由二者关系的变化后验产生，而不是对一个融合分数做阈值。

一个重要复现审计发现是：当前 4 fps + `D_anet(n=20)` 配置下，T3AL 在长度不足 2,000 帧时会退化到正负集合均包含全帧。四库 643 个测试视频中 639 个（99.38%）短于 500 秒，因此当前 test-time adaptation 几乎没有形成有效正负对比。修复互斥采样是必要底座，但不能作为论文贡献。

### 结构性空缺

1. 没有工作在严格 label-free hate localization 中进行 representation-level multimodal TTA。
2. 现有方法估计“哪个模态可靠”，但不判断 hostile material 是作者断言、引用、报道、演唱、批判还是标题/OCR 中的提及。
3. 现有 action boundary 多是物理动作变化；hate boundary 是由 target、stance、provenance 和 policy specification 决定的语义边界。
4. 高置信伪帧可能正是 quotation/OCR keyword false positive；现有 TTA 会放大 adaptation contamination。
5. 尚无方法把 epistemic uncertainty、missing/noisy modality 与 genuine semantic conflict 分开建模。

## Ranked Ideas

### Idea 1：Provenance-Gated Multimodal T3AL（推荐）

- **方法**：每个时间单元分别生成视觉、ASR、音频 evidence token；构造 `observed-hostility` 与 `author-commitment` 两个表示状态；通过来源/目标/立场的一致性门控建立互斥 positive、negative、ambiguous reservoirs；只有通过门控的证据参与单视频 adapter 更新。最后对两个状态的联合变化做 interval posterior decoding。
- **核心假设**：普通 T3AL 被高视觉相似度但无作者 commitment 的帧污染；阻止这类证据写入 adapter 可同时提高 PR-AUC、within-video ROC 和边界 F1。
- **不是简单 fusion**：多模态证据决定“谁可以更新参数”，最终分数不是固定/动态加权平均；冲突证据保留为独立状态。
- **MLLM 角色**：至多一次结构化 event proposal，输出候选 `speaker/target/act/stance/source`；第二角色可选作 counterfactual verification。MLLM 不直接产生最终边界，也不作为跨模型 teacher。
- **风险**：provenance 识别可能仍复现项目中已观察到的 assertion/mention confusion；必须在隐藏表示或可验证干预上实现，不能靠再问一次 prompt。
- **MVP**：32 视频；先修复 T3AL sampling，再比较 confidence gating 与 provenance gating；单种子，预计 <2 GPU-hour。

### Idea 2：Typed Disagreement Boundary Posterior（推荐模块）

- **方法**：将分歧分成四类：异步但互补、模态缺失、噪声、真实语义冲突。候选 change points 来自视觉 embedding derivative、utterance 边缘、speaker/audio change；动态规划输出 boundary posterior/credible interval。
- **核心假设**：边界不是“模态曲线差得最大”的点，而是 observed-hostility 与 commitment 关系发生改变的点。
- **MVP**：在缓存 A10 视觉曲线和 timestamped ASR 上做 CPU decoder；成功门槛是 F1@0.3/0.5 提升且 within-video ROC 不退化。
- **风险**：若仅用 generic variance/entropy，会与 DenoiseLoc/evidential localization 高度重合。

### Idea 3：Counterfactual Evidence-Reservoir TTA（备选）

- **方法**：对候选单元做 transcript deletion、audio mute、frame/OCR mask 等可执行干预；只有删除相关证据确实降低 hostile/commitment state 的单元进入 positive reservoir，无关干预稳定的单元提供 invariance loss。
- **核心假设**：因果贡献比原始 CLIP 相似度更能避免跨视频风格泄漏。
- **风险**：CCR 与 generic counterfactual grounding 已存在；必须服务于 reservoir eligibility，而不是仅做 score subtraction。

### Idea 4：Unbalanced Temporal OT Alignment（备选）

- **方法**：以单调、稀疏的 unbalanced optimal transport 对齐视觉帧、audio segment、ASR utterance 与 event slots；允许 speech-only/vision-only unmatched mass。
- **价值**：处理 ASR 时间漂移和音画不同步，避免强制每个时间点三模态一致。
- **风险**：若 hate semantics 弱，OT 只会恢复时间邻近性；创新容易退化为“把 OT 用到新任务”。

### Idea 5：Conflict-Preserving Multiscale Interval Process（模块候选）

- **方法**：在 1/2/4/8/16 秒尺度分别表示支持 hate、支持 non-hate、unknown、conflict 的 evidence mass，通过层级 interval DP 形成事件。
- **风险**：evidential/multiscale TAL 已拥挤，只能作为 Idea 1 的不确定性头。

### Idea 6：Speaker–Target Relation Grounding（长期方向）

- **方法**：active-speaker/diarization 将 utterance 绑定到说话者，再显式定位 speaker→target hostile relation；off-screen speech 为独立事件类型。
- **风险**：工程量大、多人/遮脸时脆弱，超过当前最小 pilot 的稳健范围。

### Idea 7：Prototype Simplex with Contextual Antagonists（仅消融）

- **方法**：attack/dehumanization/threat/exclusion/stereotype 与 quotation/reporting/counterspeech/satire 构成层级对抗 prototype geometry。
- **淘汰原因**：即使比单 query 强，也容易被正确评价为高级 prompt ensembling。

### Idea 8：Sparse MLLM-to-Dense Distillation（淘汰）

- **淘汰原因**：若使用另一模型监督 dense adapter，违反项目对 cross-model supervision 的明确 veto；即便同模型在线 self-training，也与已有 MLLM proposal/rerank 和 pseudo-label TTA 高度重合。

## Novelty Verification

Fresh novelty reviewer verdict：**POSITIVE，但 novelty 仅 LOW–MEDIUM（4/10）**。精确交叉点——四库、严格 label-free、provenance-gated representation TTA——未检索到直接同构工作；但所有子模块均拥挤。论文必须把贡献收窄为：

> 伪证据在写入 test-time representation 之前必须通过来源与 commitment 可验证性；时间边界是 observed hostility 与 author commitment 的联合状态转变。

互斥采样是 invariant；多模态 reliability 是实现；boundary posterior 是机制的时间结果。不能把三者并列包装成工程模块。最低差异要求是：provenance 必须是作用于 video-side pre-answer representation 的反事实 certificate，控制 adapter write permission；不能是 confidence/entropy/agreement、MLLM 生成的 stance label 或删掉 hostile phrase 后的普通分数下降。

## External Critical Review

Fresh critical reviewer：**POSITIVE，5.5/10**，仅表示值得做严格 kill-test。最强拒稿点是：当前方案命名了 `author commitment`，却可能无法从 video-side representation 操作性恢复它。删除字幕、静音或 OCR mask 只能证明 hostile payload 导致模型响应；quoted 与 asserted slur 都会对此敏感，因此很可能只是 generic causal relevance/confidence gating。

继续条件被收紧为：certificate 必须使用保持 payload 不变、仅切断 source binding 或 stance context 的 matched intervention；gate 在适配前由 frozen model 计算并 stop-gradient 固定。在 HateMM 与 MHC-ZH 上，控制原始 hate score 后，certificate 区分 asserted 与 mentioned 候选的 AUROC 均需达到 0.70；并且相对 coverage-matched random、confidence gate、modality-agreement gate 降低 30–50% use/mention admission，同时保留至少 80% asserted-hate admission。若 pre-adaptation certificate 失败，立即终止该 idea；不实施 boundary decoder。

| Idea | 原因 |
|---|---|
| 仅修复正负采样重叠 | correctness fix；AdaZAD 已研究 prototype-centric sampling |
| 普通 modality reliability / dynamic fusion | MC-TTA、AV²A、MultiHateLoc、LELA 已覆盖 |
| 仅用模态分数 variance 找边界 | generic uncertainty/change-point，创新不足 |
