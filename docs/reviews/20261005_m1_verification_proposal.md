## Source fidelity and adaptation

Actually read [CoVe sections 3.1–3.4](https://aclanthology.org/2024.findings-acl.212.pdf), using the primary PDF and retained extracted text. CoVe generates a baseline, plans open verification questions from it, answers questions independently without the baseline or other answer contexts in its factored variant, then generates a revised final response. The final source prompt sees the baseline and verification question–answer pairs. The separate Factor+Revise variant additionally asks explicit per-question inconsistency cross-checks.

Candidate 27 transfers the four functional phases, not every source operation. Its baseline is four neutral fields rather than a final hate answer; verification observes actual original multimodal sources rather than relying only on parametric knowledge; a deterministic typed compiler replaces queried fields, including UNKNOWN, while retaining unqueried valid fields. The final ordinary modality response sees that compiled record and original media, excluding obsolete replaced draft values. Therefore it is a **source/time-constrained multimodal adaptation of factored CoVe**, not literal section-3.4 prompt reproduction and not Factor+Revise. No source few-shot performance transfers automatically to this task.

The spec's explicit “Preserve unqueried structurally valid initial draft fields” rule and four-field final serialization govern the reader input. “Only updated fields enter” must mean the complete updated four-field record, including retained unqueried fields; it must not be implemented as dropping every unqueried field. This narrow wording clarification and the final-stage source distinction were sent to the author during this single review; neither changes the PASS verdict.
