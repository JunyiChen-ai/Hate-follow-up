## 发现与窄修复

初版validate_records仅检查extension literal和suffix_ids长度，未把token值/角色及native会话绑定到当前输入。同长度错误token或另一会话生成的extension可通过resume/prepare。

现新增validate_extension_inputs：以当前frame_paths/ASR和base自身stance，经共享Judge prefix/render/encode重建native msgs/head/history；分别核对原视觉prefix长度P与`N=P+qid+aid`的stance cache长度；重render当前tree_text用户turn和固定assistant ack，逐项核对suffix_text/IDs和extended长度。保存native_conversation及suffix_text。已确认resume每个R3已完成ID和分析prepare每个R3 ID均调用；R1/R2不强加新schema。

新增共享CPU renderer使用本地AutoConfig/AutoProcessor、原FAMILY_IMAGE_KW及Judge的原render/encode方法，不加载权重/CUDA。Program仅把原同功能helper替换为共享import；family、same_turn、image kwargs等原语义相同，增加local_files_only和所需CPU属性，不改变Program评分算法。
