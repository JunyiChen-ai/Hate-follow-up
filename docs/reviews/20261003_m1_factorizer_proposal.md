Scope: one rule-4 review of `experiments/20261003_m1_factorizer/README.md`, before implementation. The amended wrong-partition definition was included in this review. No method code or declaration was changed. No pending Attributor/Eraser performance, predictions or GT were inspected.

## Decision: PASS

The search did not establish any of the four permitted STOP grounds. Proceed to implementation and the independent rule-6 code review if the parent still needs this candidate; a supported result from the pending experiments takes priority. PASS certifies eligibility for an experiment under the repository's task-transfer criterion, not publication novelty or a prediction of success.

The defensible candidate is narrowly defined: change the information available when a frozen MLLM constructs temporal media KV states, preserve the original positions and token sequence, isolate scaffolding from media, and subsequently let queries integrate all resulting states. Independent block encoding is established prior art. Local feature extraction followed by contextual integration is also established in hateful-video research. Neither is an available broad contribution claim.

| Rule-4 STOP ground | Finding |
|---|---|
| Source mechanism already used in hateful video detection/localization | Not established for temporal media-state factorization inside the MLLM. Existing clip encoders and SafeWatch's policy-block encoding are close precedents, detailed below. The conclusion is bounded by the sources actually inspected. |
| Pure ensemble | No. Native and factorized computations use the same frozen model, with the original global margin/answer fixed. This is not combination of independently trained predictors under rule 3. |
| Pure calibration, postprocessing or smoothing | No. Attention dependencies change during prefix encoding and new local model responses are computed. Existing r6 is held fixed as an algorithm, with separate unsupervised fits; raw results are also required. |
| Pure engineering | No. This changes the evidence representation available to the local inference function and admits an explicit, falsifiable hypothesis about temporal interference. It does not merely change wording, backbone, resolution or a numerical constant. Using a mask to implement the graph is not itself a novelty claim. |

## Source verification and actual search

Searches combined `hateful video`, `hate video`, `video hate speech`, `HateMM`, and localization terms with `block attention`, `block encoding`, `independent encoding`, `parallel encoding`, `KV`, `prefix`, `mask`, and `SafeWatch`. Primary methods were inspected rather than treating keyword matches or citations as applications. Detection papers were included; neither supervised training nor a lack of temporal output automatically excludes a source from rule 4.

### Block-Attention and APE

[Block-Attention for Efficient Prefilling, ICLR 2025, official proceedings PDF](https://proceedings.iclr.cc/paper_files/paper/2025/file/a03037317560b8c5f2fb4b6466d4c439-Paper-Conference.pdf), §2.1–2.4, independently encodes context blocks and lets the final query attend across them. Its implementation includes position re-encoding and block fine-tuning; its frozen, unadapted setting is not the source of its successful accuracy-preservation claim. The requested [OpenReview page](https://openreview.net/pdf?id=7zNYY1E2fq) returned a browser challenge, so the official published PDF was read instead. The older [arXiv manuscript](https://arxiv.org/html/2409.15355v3), titled *Block-Attention for Efficient RAG*, was also read. Do not substitute the older version's experimental numbers for the published version. Factorizer accurately declares that it borrows the attention factorization, without adopting the source's adaptation, position scheme or speed claims. The source's reported unadapted degradation is a relevant experimental risk, not a rule-4 STOP ground.

[APE: Faster and Longer Context-Augmented Generation via Adaptive Parallel Encoding](https://arxiv.org/html/2502.05431v1), §4, combines independent context encoding with a shared prefix and attention temperature/scaling corrections. Those corrections address distribution differences between parallel and sequential encoding. Factorizer does not implement the full APE method and cannot inherit its accuracy or efficiency conclusions. Its shared scaffold and final joint query are within this established family.

### Closest adjacent video-safety source: SafeWatch

[SafeWatch, ICLR 2025, official paper](https://proceedings.iclr.cc/paper_files/paper/2025/file/beac6bfb7eac3d651307c16ac747df01-Paper-Conference.pdf), §3.2 and Fig. 3, is a necessary closest-source citation. PEPE independently encodes policy chunks by masking other policies and using equivalent positions; media remains available to the policy computations, followed by policy-aware visual pruning and joint decoding. It therefore already applies block separation inside a video guardrail model. Factorizer separates temporal media rather than policies and preserves native positions.

SafeWatch includes a category named *Hateful Content & Extremism*. However, the actual policy in Appendix B and the dataset breakdown describe self-harm, disturbing graphic material, antisocial behavior and depression. The inspected text does not establish protected-group hateful-video detection merely through that category name. This is a substantive task-definition boundary, not a dismissal because the paper is trained or lacks localization. Consequently this source does not establish the specific STOP ground, but it rules out claiming the first independent-block MLLM encoding for video moderation. The interpretation and the close overlap must remain visible in future novelty discussion.

### Target-task clip encoding and fusion

- [CLARA](https://arxiv.org/html/2608.15905v1), §3.2–3.4, separately extracts utterance-clip modality features, pools/projects/fuses them, and then models relations between clips with rationale conditioning. It already separates local extraction from later contextual modeling. The checked method does not factor the language-layer media KV dependency graph of a single frozen MLLM while retaining token-level query access.
- [MultiHateLoc](https://arxiv.org/html/2512.10408v1), §3, uses modality features, trained temporal representations, cross-modal interactions and MIL. Individual feature extraction is already prior art; it is not the declared MLLM prefix intervention.
- [Few-Shot Detection of Hate Videos Using Multi-Modal Large Language Models](https://doi.org/10.1145/3733813.3764370), publisher-indexed §3, independently extracts clip features with CLIP/CLAP or LanguageBind and classifies through reference-feature similarity. Parallel processing of clips is explicit. This establishes prior independent clip processing, not the Factorizer attention graph. The direct publisher open timed out; the indexed primary method section was accessible.
- [MM-HSD](https://arxiv.org/html/2508.20546), §4, studies independent modality encoders and early/late cross-modal attention over extracted features. It does not establish temporally partitioned MLLM prefilling. [RAMF](https://arxiv.org/html/2512.02743v1) likewise uses modality representations and attention-based fusion; an attention mask elsewhere in a detector is not sufficient evidence of this source computation.
- [LELA](https://arxiv.org/html/2602.09637v1), §3.3–3.4, provides local modality scores through caption-based assessment rather than factorizing the MLLM prefix. Previously inspected MATCH/LEAF/IARE/SAGE/HVGuard methods and access notes are recorded in `docs/reviews/20261003_m1_eraser_proposal.md`; those earlier readings were not treated as a new exhaustive survey here.

The [WWW 2026 explicit-evidence-attribution paper](https://doi.org/10.1145/3774905.3796488) remains a full-text access limitation from the preceding reviews. Its abstract cannot rule out an unobserved relevant mechanism. No claim of exhaustive absence or unrestricted first use follows from this search.

## Distinction from existing local experiments

Grounder and Selector modify access during queries after native prefix states already mix earlier media. Factorizer changes that earlier state construction and restores ordinary query access. Their completed failures are not a completed test of this prefix intervention. It is also distinct from Attributor's cached-value gates and Eraser's actual input deletion: it retains the input and changes encoding dependencies. Neither pending outcome was used to choose a mask or constant. No previously completed exact Factorizer experiment was identified in the reviewed records.

This difference is sufficient to test a separate computational hypothesis. It is not proof that prefix mixing caused the old failures or that delaying integration improves localization. The parent must not present this candidate as an established explanation before obtaining its own results and controls.

## Necessary precision and diagnostics

1. **Keep the structural claim conditional.** With fixed input embeddings, positions, token assignments and scaffolding, the proposed graph can prevent another temporal group's media from changing a group's prefix states. This is not independence of the final local decision: the recomputed global question, forced native answer and local queries still integrate the full prefix. It does not correct a wrong native verdict by construction. Physical edits to another frame may also change preprocessing or positions, so the specified same-position embedding intervention tests the graph rather than arbitrary input-level counterfactual invariance.

2. **Audit every route into prefix states.** The inspected installed Qwen3-VL implementation constructs vision attention segments from `grid_thw`/`cu_seqlens`; its non-Flash implementation splits those segments before attention. This is consistent with separate still-image encoding, but the implementation must verify actual image grids and deep-stack injection rather than infer independence from the language mask alone. Preserve native causal order and positions. The frames-first transcript ordering allows later speech tokens to read earlier same-window visual tokens; it does not add reverse or bidirectional cross-modal reasoning.

3. **Shared-token and scaffold rules are substantive.** `src/window_token_regions.py` can put ASR timestamp/header tokens in multiple window regions. The declared earliest-window assignment prevents those tokens from becoming a shared media bridge. Record shared and unassigned counts, including the extra out-of-duration group. A scaffold token may not read media during prefix encoding. The global-question/answer extension is deliberately outside that restriction and must be freshly computed on the factorized prefix, not copied from the native cache.

4. **Retain the amended wrong-partition definition.** Permuting group names leaves a same-group mask unchanged. The amended per-modality permutation of the assignment vector over token positions changes membership while preserving each group's modality count. Report changed allowed-edge counts/fractions; unchanged graphs are ineffective interventions. This control can also alter causal visibility and split a frame's tokens, so inferior wrong-partition performance alone cannot identify temporal semantics. The README now explicitly acknowledges that limitation.

5. **Declare the phase control exactly before running it.** “Native-prefix late query restriction” must name the existing mask, layer range and modality/answer visibility being reused. A comparison against archived Grounder's late-layer restriction changes both stage and restriction details; it can contrast complete designs but cannot independently isolate stage as the sole cause. The all-media-in-one-group control, retaining scaffold isolation, is useful for testing whether temporal grouping adds anything beyond scaffold effects. If scaffold isolation itself is claimed as a novel component, it needs a direct matched removal comparison under rule 14g; a positive full-method result alone does not establish its separate contribution.

6. **Use results that can falsify the proposed explanation.** Preserve native global margin/answer, token sequence, prompts, missing-branch behavior and raw maximum. Report paired raw and r6 metrics, all three metrics on both corpora, rank/tie changes, verdict correctness strata and branch coverage. Gains only after r6, gains replicated by an order-preserving common shift, or equal performance with all media in one group require narrowing the explanation. Attention-edge checks validate computation, not hateful evidence correctness. Any component claimed as novelty remains subject to rule 14g.

7. **Report actual extra inference cost.** The declared deployment counts, native `3+B` and Factorizer `5+B`, expose one additional full prefix encoding and the recomputed question/answer extension. Paired `6+2B` reuses the native global assessment. A roughly 68 MB BF16 mask at about 5,800 tokens is only the mask storage; peak memory and latency include model attention workspaces and implementation behavior. The 20–40 GPU-minute estimate must be replaced by smoke-based timing before the full run and by measured per-corpus totals afterward. No sparse-kernel speedup is established.

Before implementation, minimally add SafeWatch and the already-established clip-encoding boundary to the declaration; make the phase-control configuration explicit before that control runs. These are source/experiment precision requirements, not additional rounds of proposal review. The candidate remains an untested task transfer, and the paper/current method should change only after the declared empirical gates pass.
