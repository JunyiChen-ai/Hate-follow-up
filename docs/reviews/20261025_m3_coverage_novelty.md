7. 有害视频审核里的比例 → HarmVideoBench、DIH、VHD11K，都没有份额读数。

9. 概率加权、MLLM、仇恨或毒性 → **Video-SafetyBench 的 RJScore**：对 5 个分数 token 做 softmax，取 Σk·p(k)。它评判的是视频 LVLM **生成回答**的毒性，用来算越狱攻击成功率，阈值按人工标注定。这不是对视频内容的检测或定位。
10. 用比例优势 / cumulative logit 从选项概率读数 → CORDIAL 2609.29807 把序数选项概率当作带噪读数，要用少量标签校准，而且是文本任务。

13. 零样本 TAL 的 coverage → OZ-TAL 只把 coverage 当作评测分层，模型不预测它。
14. MARS / TANDEM / SafeLens / HVGuard 的读出 → 都是推理式裁定或经过训练。
15. Q-Align → 对等级 token 概率加权平均，用于画质和视频质量评估，需要训练。
16. 扩展检索 → CLUE（CVPR 2025）用 Yes 的概率判图像安全；LELA。

结论：没有找到仇恨视频检测或定位工作读取整段视频的违规份额，也没有找到用选项分布期望或序数潜变量做读出的。来源方法在别处用过，但都不是仇恨视频：G-Eval、RJScore（评判生成回答）、Q-Align（质量评估）、quantification（文档流行率）、比例优势模型（McCullagh 1980）。

## 四种 STOP 情况

1. **来源方法已用于仇恨视频**：不成立，见上面的检索。
2. **纯 ensemble**：不成立。只有一个 MLLM，用同一个前缀。A2 / A2η 把同一模型的两个视频层读数相加，与 r6 的"裁定 + 窗均值"同类。规则 3 明确允许同一 MLLM 的整段判断与逐段判断。
3. **纯校准 / 后处理 / 平滑**：不成立。份额是一次新的模型读数，不是对已有分数的变换。A1 和 A1η 还去掉了两高斯校准。A2 系列保留的校准是 r6 原有的部件，本候选不主张它。
4. **纯工程技巧**：不成立。本候选不是只改提问措辞：
   - 被估计的量从"有没有"换成"占多少"；
   - 新增了一个视频层读数分支；
   - 读出从 Yes/No 对数几率换成分布期望或序数潜变量；
   - 键的构成改了，A1 不再做校准；
   - 有明确的机制假设：跨视频比较时，帧分的最优值就是该视频的份额，直接估计应优于窗均值这种 classify-and-count 式的估计；
   - 预检 P1–P3、门 G1–G2 和 14g 消融都在运行前写定。

   这是 M3 机制的完整改动。需要说明：期望读出本身不新，不能作为主张；可主张的只有被估计的量和它与 pooled 排序之间的对应关系，最后由 14g 决定。

**η 是否改变判断**：不改变。η 是同一次新读数上六个概率的另一种读出，即比例优势模型的潜变量。它不新增测量，也不把候选变成纯后处理，因为它作用在新测量上。检索中没有找到仇恨视频工作用过这种读出。臂从 2 个增加到 4 个，并按 test 结果选定，这属于规则 7 / 10 的 development-selected 标注问题，不属于规则 4。冒烟测试里选项分布接近 one-hot，而且跟着裁定走。这是"裁定换了个名字"的预警，但规则 4 不允许据此 STOP，交给 P3 判断。
