# M1 / M3 novelty team, 2026-10-25

Team records copied from the session scratchpad after the round ended. Files:
- `charter.md`: the user's request (verbatim), goal, criteria, current method, team.
- `history.md`: every past M1 / M3 attempt, closed families, open neighbourhoods, caches on disk, exact r6 code and prompts.
- `lit_m1.md`, `lit_m3.md`: literature for M1 (about 50 works) and M3 (about 45 works).
- `design_m1.md`, `design_m3.md`, `design_story.md`: proposals of the three designers, with CPU checks and dropped ideas.
- `review_m1.md`, `review_m3.md`: adversarial reviews (verdicts, reconciled evidence, pre-check protocols).
- `lead_log.md`: lead's log.

Paths inside these files that start with the scratchpad folder `.../m1m3_novelty/work_<name>/` now live in
`runs/20261025_m1m3_team/work_<name>/` on uoa-lab1 (scripts and small outputs). The composed read sets
(`reads/`) and decoded `predictions.jsonl` files were not kept; `work_review_m1/build_controls.py` rebuilds them from
the cached reads it names. All numbers are development-selected (read on test). The one GPU run of the round is
candidate 50: `archive/experiments/20261025_m1_act_state/`.
