## 核心路径核对

树构建实际执行4/8/16 breadth，逐轮完整 caption/relevance；按停止条件保留最后根集，未将拒绝轮成本丢弃。根相关性1/2/3分别决定0/1/2层向下扩展；每层最多二分，singleton/不可分停止，节点分区覆盖父成员。代表取真实member到FP32中心的最近者，并按真实时间/index解平局；没有以中心向量伪装帧。caption只对同一pool member/source index复用，caption缓存覆盖被拒绝breadth轮的生成与费用。

唯一Qwen视觉tower直接编码原帧，processor使用共享尺寸参数，merged embedding逐图FP32空间均值后L2归一化。HF4.57返回tuple首项；目标HF5.15的 `pooler_output` 在 get_image_features 内已按image_grid拆成逐图tuple，两个明确分支均与实现一致。图像数、每图merged token数和像素上限有实际断言，不采用另一encoder。

PyAV源时间使用真实PTS/timebase与container origin，1fps目标取其后首个真实帧，同一源index去重。缺pool帧的8秒窗只能从该窗已解码帧补最近中心的真实帧；无实际帧显式记录，禁止跨窗伪补。Witness重新seek对应实际absolute/PTS并核对尺寸后保存源像素；局部图像路径由源index生成。叶候选只在本窗成员内选，最终最多两张不同源帧；祖先包保持自身真实caption/time且只按节点ID去重。

digit relevance验证1/2/3是互异single token，调用共享FP32 restricted logprob后argmax，平局选较早数字；每节点cache crop并恢复delta。caption是真实代表图的独立单图prompt，无ASR/全局判决，贪心EOS/96token限制与截断记录明确。

new context确实将完整最终树记录插入原转录与policy之间，重新读取global并以自身hard stance进入局部读数。局部新增真实图像连同ancestor包进入模型；speech在相同new context用原问题/body独立重读。record将new global、new visual、new speech直接写入供固定r6使用的字段，未择优或混入native预测。native另行原样完整读取，并由prepare/最终六指标检查精确复现。

appended-image路径合并完整前缀与suffix token IDs及全部image grids，按目标模型接口提供mm_token_type_ids计算完整mRoPE；确认prefix positions不变后，只将新suffix positions输入缓存forward。新增图像像素只对应suffix placeholders。每分支在finally恢复cache长度与原delta；speech再次重置delta。smoke首窗额外核对完整render重新编码得到的IDs/grids与拼接结果精确相同。实际GPU数值及接口运行仍须smoke验证，不能仅凭位置源码检查声称真实模型parity。

提取/评分不读GT、历史prediction或metrics；ASR仅由共享loader加载。派生缓存核对可读版本、常数、模型、manifest/实际ID、特征shape、成员/中心、packet与witness存在性。续跑核对既定ID唯一覆盖、配对记录、当前tree文本/packet及ASR identity，失败不静默略过。输出记录真实语言/视觉forward、所有caption、pool和local图像数及预处理/读取时间；已复用缓存保存原新视频成本。smoke的fresh-render编码检查含在其测量时间中，完整main没有该额外验证开销。

analyze仅通过subprocess调用唯一canonical4fps evaluator和固定twolevel_r2配置；逐视频排序调用共享within helper，没有复制评测算法。三指标并列、native六指标精确、相同主项双语料+.01与各项噪声下限方向正确。full评分后才访问GT；smoke只prepare。机制标记保持False，完整控制尚未实现/运行不能被描述为已经支持的证据。
