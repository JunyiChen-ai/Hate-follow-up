## Original findings (all resolved within this review)

1. **Interrupted source collection cannot restart.** `read_video` preserves dense
   blocks on failure, while a newly constructed `VideoMemory` starts its block
   count at zero and refuses to overwrite the existing `block_000000.npy`.
   Retrying an incomplete video therefore fails instead of rebuilding its
   temporary memory. Use a fresh owned attempt directory or equivalent explicit
   recovery that preserves inputs and raw results. Reproduced independently.
2. **Completed records can be reused under changed native inputs/runtime.**
   `measure.main` overwrites the run config before reuse validation;
   `validate_bundle` checks current source inputs and speech but does not bind
   native image pixels or execution runtime/config. `analyze.prepare` rebuilds
   native text/grid/position geometry, which does not detect a same-shape image
   replacement. Independently replacing native image pixels left the original
   bundle accepted. Bind actual native input contents without hashes and reject
   incompatible run configurations before overwriting provenance.
3. **Reported costs omit required actual work.** Synchronized deployment
   component timings cover the main forwards, source memory write/read and
   query transfer work, but do not cover the repeated full-video validation
   decodes, processor proof replays, proof/result writes, or complete run wall
   time. These are actual executed work under the declared cost contract. Keep
   deployment component estimates separate and record preparation, validation,
   proof I/O and complete attempt/resume costs, including failed work.
